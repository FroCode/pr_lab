# MedCore AI - Interdisciplinary Medical Platform

This project is a submission for the Project Laboratory requirements. It bridges Computer Science with Medicine through AI-driven diagnostic logic and health data visualization.

## 🚀 Getting Started
1. **Install Dependencies**: `npm install`
2. **Run Dev Server**: `npm run dev`

## 🏥 Project Overview
MedCore AI provides:
- **AI-Driven Symptom Checker**: Preliminary diagnostic logic mapping symptoms to medical advice.
- **Patient Dashboard**: Interactive health trends (BPM) using Recharts.
- **Doctor Portal**: Oversight portal for monitoring patient alerts and insights.

## 🛠 Tech Stack
- **Frontend**: React (Vite)
- **Styling**: Vanilla CSS (Custom Med-Glassmorphic Design)
- **Visualization**: Recharts
